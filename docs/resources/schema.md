# naming_schema (Resource)

Resolves a naming schema from a bundled convention, an optional partial override, and runtime parameters - and persists a random unique id for use in generated names (e.g. the `<UNIQUE_ID_n>` pattern token).

## Example Usage

```terraform
resource "naming_schema" "this" {
  convention = "default"

  # Optional partial override - see examples/basic/naming.yaml for the
  # merge semantics (deep-merged abbreviations/mappings, wholesale-replaced
  # patterns).
  # naming = "${path.module}/naming.yaml"

  parameters = {
    location    = "westeurope"
    environment = "development"
    name        = "myapp"
  }
}

output "storage_account_abbreviation" {
  value = naming_schema.this.abbreviations.Azure["Microsoft.Storage/storageAccounts::default"]
}

output "storage_account_pattern" {
  value = naming_schema.this.patterns.Azure["Microsoft.Storage/storageAccounts"].default
}
```

## Schema

### Optional

- `convention` (String) Name of the bundled convention to load (e.g. `"default"`). Defaults to `"default"`.
- `naming` (String) Path to a custom YAML file that partially overrides the bundled convention (e.g. `"${path.module}/naming.yaml"`). Any key left unset in it falls back to the bundled convention, except `patterns`, which is replaced wholesale when set.
- `parameters` (Dynamic) Runtime parameters (`location`, `environment`, `name`, ...) used when rendering names.
- `random_seed` (String) Optional seed for the generated unique id. The same seed always produces the same id (a deterministic UUID derived from it). If unset, a random id is generated once on create and kept stable across updates.

### Read-Only

- `abbreviations` (Dynamic) The merged abbreviations table.
- `default_parameters` (Dynamic) Normalized copy of `parameters` (an empty object if `parameters` was left unset).
- `enforce_lower_case` (Dynamic) The resolved lower-casing settings.
- `id` (String) Same value as `random.uuid`.
- `index_modifier` (Dynamic) The resolved index offset (e.g. `1` so indices start at `01`).
- `mappings` (Dynamic) The merged mappings table.
- `patterns` (Dynamic) The resolved patterns table.
- `random` (Attributes) A random source for generating unique naming ids. Generated once and kept stable across updates. (see [below for nested schema](#nestedatt--random))
